## 📌 О проекте
**«ОБЖ.ПРО»** — это современное одностраничное веб-приложение (SPA), разработанное для быстрого и наглядного изучения школьниками алгоритмов выживания в экстремальных и чрезвычайных ситуациях.

### Разделы портала (7 интерактивных модулей):
1. 🛸 **Атака БПЛА (беспилотников)** — действия в помещении, на улице, в транспорте и при обнаружении обломков.
2. 🏫 **Нападение на школу (Скулшутинг)** — правила поведения на уроке (выполнение указаний учителя, баррикадирование), на перемене и при штурме спецназа.
3. 🌊 **Наводнение и паводок** — эвакуация, выживание в потоке воды и безопасность после спада воды.
4. ☢️ **Ядерный удар и радиация** — защита от вспышки, ударной волны, герметизация и дезактивация.
5. 🔥 **Пожар в здании** — эвакуация при задымлении и первичные средства пожаротушения.
6. ⚠️ **Утечка бытового газа** — предотвращение взрыва газовоздушной смеси.
7. 🧰 **Первая помощь** — остановка кровотечений, боковое положение и сердечно-легочная реанимация (СЛР).

## 💻 Стек технологий
* **HTML5** — семантическая структура приложения.
* **Tailwind CSS** — современная адаптивная верстка в стиле *Glassmorphism* (Dark UI).
* **Vanilla JavaScript (ES6)** — интерактивное переключение сценариев, логика тестирования, подсчет результатов.
* **Web Storage API (`localStorage`)** — сохранение прогресса обучения и собранного «Тревожного чемоданчика» в браузере пользователя без использования платных серверов.
* **PptxGenJS** — автоматическая генерация презентации проекта в формате `.pptx`.
